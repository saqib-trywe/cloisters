# Inherited decisions

A frozen snapshot of the planning record of **tikka**, the Scala predecessor of cloisters, taken
2026-10-24 from commit `b022de9` (2026-09-19) of `saqib-trywe/tikka`.

Cloisters carries these decisions over wherever they still apply. The map
([.wayfinder/MAP.md](../../.wayfinder/MAP.md)) says which: an "Inherited" line means the ticket here
holds the decision as written (read "tikka" as "cloisters", `TIK` as `CLO`); anything Scala-specific or
touched by the wiki is re-decided in a fresh cloisters ticket, which overrides the snapshot.

Never edit these files. They record the route tikka walked, not cloisters' current state.

- [MAP.md](MAP.md) — tikka's map, with its Decisions so far
- [tickets/](tickets/) — every resolved tikka ticket (read to the end: *Amended by* notes override)
- [CONTEXT.md](CONTEXT.md) — tikka's glossary at the time
- [adr/](adr/) — tikka's ADRs
- [build-plan.md](build-plan.md) — tikka's milestone plan
